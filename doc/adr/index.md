## 什么是 ADR？

架构决策记录（Architecture Decision Record）是一种轻量级的文档格式，用于记录重要的架构决策及其上下文。

每条 ADR 包含：
- **标题**：简洁描述决策内容
- **状态**：提议、已接受、已废弃、已替代
- **上下文**：为什么需要做这个决策
- **决策**：具体做了什么决定
- **后果**：决策带来的影响（正面和负面）

## 新建 ADR

```bash
# 创建新 ADR（按序号递增）
mkdir -p doc/adr
touch doc/adr/0001-<title>.md
```

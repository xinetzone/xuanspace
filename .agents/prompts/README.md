# 提示词库

Xuanspace 项目 AI 智能体协作提示词集合。

## 角色提示词

| 角色 | 文件 | 说明 |
|---|---|---|
| 项目管理者 | `project-manager.md` | 项目管理、任务规划、进度跟踪 |
| 开发者 | `developer.md` | 代码开发、bug 修复、功能实现 |
| 审查者 | `reviewer.md` | 代码审查、质量检查、最佳实践 |

## 使用方式

在对话中引用对应角色的提示词，使 AI 智能体以特定角色视角执行任务。

## 3. E — 模式萃取（可跨场景迁移）

> 每个模式给出：触发场景 → 步骤（3–7）→ 反模式 → 迁移边界。这些模式不依赖 Python，也不依赖 xuanspace。

### P1　能力键（Capability Key）

- **触发**：两个以上模块需要互相调用，但希望"调用方不感知提供方是哪个发行包"。
- **步骤**：
  1. 定义键语法：`<域>:<子域>/<所有者>#<接口>`（例：`xuan:cli/commands#register`）。
  2. 键与实现解耦：实现可来自任意发行包，键必须稳定。
  3. 调用方只声明"我需要这个键 + 结构约束"，不声明包名。
  4. 提供方在装配期登记键；同名冲突按优先级/显式选择解决。
  5. 门禁校验键的唯一性与命名空间归属（谁的域谁负责）。
- **反模式**：用模块路径当身份（重构即破坏契约）；用包名当身份（无法多提供者）；用字符串版本号比较兼容性（F16）。
- **迁移**：任何"注册表 + 字符串键"的代码都可套用。

### P2　可撤销装配（Revertible Assembly）

- **触发**：需要在同一进程内反复装载/卸下能力（调试、A/B、按需启停、测试隔离）。
- **步骤**：
  1. 规定唯一的登记入口，返回值必须是句柄（`Disposable`）。
  2. 复合句柄用栈语义：后登记先撤销，子句柄自动归并到父。
  3. 撤销不得吞异常：异常聚合上报，但必须继续撤销其余句柄。
  4. 装配结束做"零残留"断言（关键表长度为 0、钩子数回到基线）。
  5. 失败路径必须回滚到装配前快照（事务语义）。
- **反模式**：`atexit` 兜底；模块级可变单例；卸载时 `try/except: pass`（S13 现症）；"重启即卸载"。
- **迁移**：C 扩展只承诺句柄可撤销，不承诺库可卸载（见 V1）。

### P3　版本化上下文（Epoch Reload）

- **触发**：提供方实现变化后，希望只重载受影响的下游，而不是全量重启。
- **步骤**：
  1. 依赖身份 = `(键, 实现摘要, 配置摘要)`，而非对象地址。
  2. 每次登记/替换后，对依赖集包含该键的组件重算身份。
  3. 身份不变 → 中性（不动）；由无到有 → 激活；由有到无 → 停用；两端都有但不同 → 先卸后载。
  4. 依赖不可得 → 置 INACTIVE，不抛错；依赖出现后自动激活。
  5. 传播必须有界：一次变更的重载集合 = 依赖传递闭包，且不得包含无关节点。
- **反模式**：用 `id()`/对象引用做身份（S12）；全量 reload；把"依赖缺失"当异常。
- **迁移**：前端状态库、配置中心热更新、CI 缓存失效判定均可用同一模型。

### P4　声明视图对账（Committed / Target View Reconciliation）

- **触发**：期望状态（配置/清单）与现实状态（已加载实例）可能不一致，需要收敛且可复现。
- **步骤**：
  1. 定义 target view（期望）与 committed view（已生效），二者结构同构。
  2. 逐字段 diff（来源、隔离、拦截、配置、启用位），未变字段不触发动作。
  3. 按依赖拓扑施加变更，任一步失败则整批回滚到旧 committed view。
  4. 收敛后断言静默：所有 ACTIVE 节点依赖可解，且不存在可激活而未激活的节点。
  5. 把 committed view 落盘为凭证，供下次启动与 CI 比对。
- **反模式**：人工维护快照（S4/I4）；"配置改了但只有重启才生效"；部分应用后不记录实际状态。
- **迁移**：K8s reconcile、数据库迁移、构建系统增量判定。

### P5　多提供者与作用域（Multiplex & Scope）

- **触发**：同一能力存在多个实现（多后端、多算法、多区域），或不同插件应看到不同能力子集。
- **步骤**：
  1. 键的元数据标注 `single | multi`。
  2. `multi` 键按清单 `priority` 降序定序，消费者可用 `provider = "..."` 显式覆盖；`priority` 相同且未显式指定时装配期报错（见 ADR-05）。
  3. 作用域（scope）限定某插件可见的键集合，越界访问记 UNDECLARED_ACCESS。
  4. 多提供者变更只影响选择结果变化的调用方。
- **反模式**：`providers[0]` 隐式取第一个（P2-10 前 `ServiceRegistry` 的典型退化，现已按 ADR-05 收口）；用 if/else 在业务代码里挑后端。
- **迁移**：任何"插件 + 策略选择"场景。
